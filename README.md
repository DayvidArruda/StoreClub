# 🛍️ StoreClub - E-commerce Front-end

O **StoreClub** é um projeto de loja virtual desenvolvido para colocar em prática conceitos avançados de design responsivo e experiência do usuário (UX) em interfaces de compras.

> **Status do Projeto:** Concluído / Em evolução 🚀

## 🎯 Objetivo
Demonstrar a criação de um catálogo de produtos moderno, com foco em usabilidade, organização de componentes e fidelidade ao design em diferentes tamanhos de tela (Mobile e Desktop).

## 🛠️ Tecnologias Utilizadas
- **HTML5**: Estruturação semântica para melhor SEO e acessibilidade.
- **CSS3**: Estilização avançada com Flexbox para garantir o alinhamento perfeito dos cards de produtos.
- **JavaScript**: Lógica para interatividade (ex: botões de compra, filtros ou menus).

## ✨ Funcionalidades
- **Grid de Produtos**: Exibição organizada de itens com imagens e preços.
- **Design Responsivo**: Interface adaptada para smartphones, tablets e desktops.
- **Navegação Intuitiva**: Menu e botões de ação (Call to Action) bem posicionados.
